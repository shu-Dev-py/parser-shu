🎮 Telegram-Бот: Игровой Ассистент с Базой Данных и ПарсингомTelegram-бот, созданный в качестве курсового/дипломного проекта.

## ✨ Особенности проекта
* **Асинхронность:** Построен на `aiogram 3.x` с использованием архитектуры `async/await`, что обеспечивает высокую скорость обработки запросов.
* **Умный поиск игр:** При вводе частичного названия (например, `pubg`) бот выполняет SQL-запрос с оператором `LIKE` и предлагает точные варианты в виде Inline-кнопок (например, `PUBG` и `PUBG Mobile`).
* **Безопасность:** Конфиденциальные данные (токен бота) вынесены в изолированные переменные окружения (файл `.env`).
* **Локальный кэш каталога:** Предварительно собранная база данных позволяет боту мгновенно определять существующие категории, не перегружая сайт FunPay частыми запросами к главной странице.

## 📂 Структура репозитория
* `main_parser.py` — Основной модуль Telegram-бота (инициализация, хэндлеры, логика FSM).
* `parser.py` — Скрипт для парсинга актуальных цен и топ-5 товаров с FunPay с помощью `BeautifulSoup4`.
* `titile_game.py` — Скрипт первичного сбора названий всех игр и категорий с сайта в Excel-документ.
* `bd_games.py` — Скрипт для создания таблиц и миграции данных из Excel-файла в базу данных SQLite3.
* `funpay.db` — Локальная база данных SQLite3 с проиндексированными играми и категориями.
* `funpay_games_structure.xlsx` — Промежуточный Excel-документ со структурой каталога площадки.
* `requirements.txt` — Список зависимостей и библиотек, необходимых для работы проекта.
* `.env` — Файл конфигурации переменных окружения (скрыт из соображений безопасности).

## 🛠 Стек технологий
* **Язык программирования:** Python 3.10+
* **Фреймворк бота:** aiogram 3.x
* **Парсинг данных:** BeautifulSoup4, requests, openpyxl
* **База данных:** SQLite3

## 🚀 Инструкция по развертыванию и запуску

### 1. Подготовка окружения
Клонируйте репозиторий и создайте виртуальное окружение:
```bash
git clone https://github.com
cd otchet
python -m venv venv
```

Активируйте виртуальное окружение:
* **Windows:** `venv\Scripts\activate`
* **Linux / macOS:** `source venv/bin/activate`

Установите все необходимые зависимости:
```bash
pip install -r requirements.txt
```

### 2. Настройка конфигурации
Создайте в корневой директории файл `.env` и добавьте в него ваш токен от [@BotFather](https://t.me):
```env
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

### 3. Первоначальное наполнение БД (при необходимости)
Если базу данных требуется обновить или собрать заново:
1. Запустите `python titile_game.py` для генерации актуального файла `funpay_games_structure.xlsx`.
2. Запустите `python bd_games.py` для импорта собранной структуры в файл базы данных `funpay.db`.

### 4. Запуск Telegram-бота
```bash
python main_parser.py
```

## 🤖 Демонстрация работы сценария
1. Пользователь отправляет команду `/start` и вводит ключевое слово (например, `pubg`).
2. Бот обращается к `funpay.db` и генерирует Inline-кнопки со всеми похожими играми (`PUBG`, `PUBG Mobile` и т.д.).
3. После выбора конкретной игры бот предлагает выбрать категорию товара (например, *Валюта*, *Аккаунты*, *Услуги*).
4. На основе выбора запускается парсер `parser.py`, который извлекает HTML-код страницы, формирует список и возвращает пользователю **топ-5 самых актуальных предложений** с ценами и прямыми ссылками.
