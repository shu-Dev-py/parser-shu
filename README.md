🎮 Telegram-Бот: Игровой Ассистент с Базой Данных и ПарсингомTelegram-бот, созданный в качестве курсового/дипломного проекта. Он позволяет пользователю выбрать жанр или название игры из встроенной базы данных, а затем автоматически парсит и выводит 5 лучших предложений по выбранной игре с популярной торговой площадки.📌 Основной функционал📂 Каталог игр: Выбор игр из локальной базы данных.🤖 Генерация рекомендаций: Выбор игры пользователем из выпадающего списка или через команды.🔍 Парсинг цен: Автоматический сбор 5 лучших товаров/аккаунтов с площадки FunPay по выбранной категории.💬 Удобный интерфейс: Взаимодействие с ботом реализовано через кнопки (Inline-клавиатуры). 🛠 Стек технологий Язык программирования: Python 3.10 Основные библиотеки: aiogram, BeautifulSoup4 для парсинга. База данных: SQLite3.
